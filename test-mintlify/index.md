# Welcome to Documentation Tools

This is a collection of useful tools for domain and email management.

## Available Tools

- [Email Validator](/components/email/EmailValidator) - Validate email addresses and check their deliverability
- [Domain Age Checker](/components/tools/DomainAgeChecker) - Check how long a domain has been registered
- [Domain Blacklist Checker](/components/tools/DomainBlacklistChecker) - Check if a domain is listed in common blacklists

## Getting Started

1. Choose a tool from the navigation menu
2. Enter the required information
3. View the results
